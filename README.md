# Business ERP System (Odoo ERP)

## Overview

A custom Odoo-based ERP system developed for vehicle inventory management, customer management, sales tracking, invoicing, VAT calculations, dashboard analytics, and business workflow automation.

This project demonstrates enterprise application development using the Odoo framework with PostgreSQL integration.

---

## Features

### Vehicle Inventory Management

* Vehicle stock management
* Vehicle categories
* Buying & selling prices
* Stock quantity tracking
* Low stock alerts
* Vehicle image uploads
* Vehicle status tracking

### Customer Management

* Customer records
* Contact details
* Email management
* Customer type classification

### Vehicle Sales Management

* Vehicle sales records
* Customer linking
* Profit calculation
* Automatic stock reduction
* Payment status tracking

### Invoice Management

* Auto-generated invoice numbers
* VAT calculation (18%)
* Grand total calculation
* Payment workflow buttons

### Dashboard & Analytics

* Total vehicles
* Total customers
* Total sales
* Total profit
* Graph analytics
* Search & filtering

## Installation

1. Clone repository
2. Place module inside Odoo custom addons directory
3. Configure PostgreSQL database
4. Run Odoo server
5. Install module from Apps menu
